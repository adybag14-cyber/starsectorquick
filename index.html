📋 Project Overview

StarSector 2 is an ambitious project that brings a Java-based space simulation game to the web browser using cutting-edge WebAssembly technology. By leveraging CheerpJ, we can run Java code directly in the browser with near-native performance.

⚙️ Technology Stack

This project utilizes a sophisticated technology stack to achieve browser-based Java execution:

CheerpJ 4.2 WebAssembly Emscripten LWJGL GL4ES OpenGL Maven GWT Java 8

Core Components

  • CheerpJ Runtime: Java-to-WebAssembly compiler and runtime
  • Memory Mapping Utils: Efficient buffer management for graphics operations
  • GL4ES: OpenGL to WebGL translation layer
  • LWJGL: Lightweight Java Game Library bindings
  • AWT Polyfills: Abstract Window Toolkit browser compatibility
